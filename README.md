# Images Gallery

Minimal React/Flask full-stack exercise centered on an image-gallery UI.

The visible source is a small React frontend scaffold. The repository is useful mainly as an older public example of web-application setup, project structure, and frontend/backend direction.

## What It Shows

- React frontend scaffold and component structure
- Full-stack application layout intended for a Flask-backed gallery
- Earlier public web-app experimentation
